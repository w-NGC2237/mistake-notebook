# 考公错题本

拍错题 → 自动识别文字 → 自动判断模块和题型 → 变成可以反复刷的题。

有两种用法，数据各自独立，互不影响：

| 用法 | 说明 |
| --- | --- |
| **手机 App**（推荐） | 装到安卓手机上，完全离线运行，不联网、不需要电脑，数据存在手机里 |
| **电脑 + 浏览器** | 电脑上跑一个本地服务，手机连同一个 WiFi 也能用，识别精度更高 |

---

## 一、手机 App

安装包已经打好了，就是项目根目录的 **`考公错题本.apk`**（24 MB）。

### 怎么装到手机上

1. 把 `考公错题本.apk` 传到手机（微信传文件、数据线拷贝、网盘下载都行）。
2. 在手机上点开这个文件。
3. 系统会提示"禁止安装未知来源应用"，按提示允许一次即可（不同手机路径略有差别，
   一般在"设置 → 应用 → 特殊应用权限 → 安装未知应用"里给你用的那个 App 授权）。
4. 装完后桌面会出现一个紫色底、白色"错"字的图标。

装好之后**完全离线可用**：飞行模式下也能拍照导入、识别、刷题。

### App 里的能力

图片识别用的是 PP-OCRv5 模型，跑在手机本地，和电脑端是同一套模型，中文识别效果一致。
首次打开会花一两秒加载模型，之后每张图识别大约 2-5 秒（取决于手机性能）。

数据存在手机的 IndexedDB 里，卸装 App 会一起删掉。换手机时用
**统计页 → 导出备份** 存一个文件，在新手机上用 **恢复备份** 导入即可。

## 二、电脑 + 浏览器

双击 `启动错题本.bat`。第一次会自动装环境（3-5 分钟），之后每次点开就能用。
启动后浏览器会自动打开 `http://127.0.0.1:8765`。

**手机上用浏览器访问**：电脑和手机连同一个 WiFi，在手机浏览器打开启动窗口里显示的
`http://192.168.x.x:8765`，再点"添加到主屏幕"，也能像 App 一样用。
这种方式识别走电脑的 CPU，速度更快，而且数据集中在电脑上便于管理。

## 四个页面

| 页面 | 作用 |
| --- | --- |
| 导入 | 拍照或选相册图片，可以先框选题目范围，自动去笔迹 + 扶正 + OCR + 拆题 + 分类，确认后入库；也可以直接粘贴文字 |
| 错题本 | 按模块 / 状态 / 关键词筛选，点开可编辑、删除、单独重做 |
| 刷题 | 按模块 + 二级题型组卷，限时提示、自动判分、勾选错因、按遗忘曲线排复习 |
| 统计 | 模块分布、各模块正确率、薄弱题型排行、错因分布、题源分布、导出与备份 |

**复习节奏**：做对往后推一档（1 → 2 → 4 → 7 → 15 → 30 → 60 天），做错回到当天。
"今天该复习的"就是按这个算出来的。

## 识别是怎么做的

**文字识别**：PP-OCRv5 的检测 + 识别 ONNX 模型，通过 onnxruntime-web 在浏览器/WebView
里以 WASM 运行。电脑端用 RapidOCR（同一族模型），两边识别效果一致。
App 里模型随安装包一起带上，不联网、不限量。

**识别前的图片处理**（拍照的三种常见毛病都在这一步解决）：

- **去手写笔迹**：红笔、蓝笔批注的饱和度很高，印刷黑字几乎没有饱和度，按"饱和度 + 色差"
  两个条件筛出来擦成白色。铅笔的浅灰细线靠"周围没有很黑的像素"来和印刷字区分。
  笔迹边缘会向外多擦一圈，避免残留的小尾巴被识别成逗号句号。改过的图在导入卡片上会显示
  "已擦除手写笔迹"，可以点"重新裁剪识别"重来。
- **自动扶正**：手机拍照很难端平，图一歪，同一行的文字就会被切成两行，
  出现"错行"。程序会用投影法估计文字行的倾角（±10° 以内），把图转正再识别。
- **框选范围**：一张照片里往往有好几道题。选完图后点缩略图上的"裁剪"，拖方框只保留要识别的
  那一块，其他内容不会混进来。裁剪框四角可以拉伸，工具栏里能实时预览处理效果。

这三个开关都在「统计 → 数据与设置」里，默认全开。觉得哪一项处理过头了（比如浅色印刷字被
误擦），可以单独关掉。

**拆题**：按 `1.` `1、` `(1)` `一、` 切分，然后抽出选项、`【答案】`、`【解析】`。
针对考公题目专门处理了两个常见问题：

- 选项被 OCR 挤成一行（`A.25天B.30天C.28天D.32天`）能自动切开；
- 数学题干里的 `设A、B两点` 不会被误判成 A、B 两个选项。

**题型判断**：关键词打分 + 结构特征。纯数字序列直接锁定数字推理；
`最能削弱/加强上述论证` 锁定论证推理；`不属于上述定义` 锁定定义判断。
置信度低的题目会在导入卡片上标黄提醒。

**纯图片题**：图形推理、统计图表这类题 OCR 出来几乎没有文字，会自动标成"图片题"、
保留原图，并提示手动选题型。做题时看原图作答。

**笔迹盖住文字的情况**：如果红笔正好圈在选项上把"A."盖掉了，解析器还有一层兜底规则——
只要一行里能连出 A、B、C、D，就算分隔符缺失也会按选项处理。所以" A 25天 B.30天 C.28天"
这种残破的也能救回来。

## 重新打包 App

改完 `static/` 里的任何东西（界面、分类规则、样式）之后，在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File tools\build_apk.ps1
```

脚本会依次组装网页资源、同步到安卓工程、编译发布版 APK，最后把结果拷成根目录的
`考公错题本.apk`。首次编译要下载 Gradle 和安卓依赖，之后每次只要一两分钟。

改了 `classifier.py` 里的分类词表后，需要先重新生成 JS 版规则：

```powershell
.venv\Scripts\python.exe tools\gen_classifier_data.py
```

然后跑打包脚本。

### 关于签名

`app/android/kaogong-release.keystore` 是给这个 App 签名用的证书，密码是 `kaogong2026`。
**不要删掉它** —— 安卓要求同一个应用的更新必须用同一个证书签名，丢了它就只能卸载重装
（数据也会一起丢）。想换成自己的密码，改 `app/android/app/build.gradle` 里的
`signingConfigs.release`，或者设置环境变量 `KAOGONG_KEYSTORE_PASSWORD`。

## 目录结构

```
考公错题本.apk        打好的安卓安装包
启动错题本.bat        电脑端一键启动

server.py            电脑端后端：接口、数据库、复习调度、统计
ocr_engine.py        电脑端 OCR（RapidOCR）
parser.py            拆题、抽选项和答案（Python 版）
classifier.py        考公模块 / 题型分类规则（Python 版）

static/              网页界面（电脑端和 App 共用同一套代码）
  app.js             界面逻辑
  lib/classifier.js  分类规则（JS 版，逻辑与 classifier.py 一致）
  lib/classifier_data.js  分类词表，由 tools/gen_classifier_data.py 从 Python 导出
  lib/parser.js      拆题（JS 版）
  lib/localdb.js     手机本地数据层（IndexedDB）
  lib/localocr.js    手机本地 OCR（PP-OCRv5 + onnxruntime-web）
  lib/imageproc.js   识别前的图片处理（去手写笔迹 + 自动扶正）
  lib/crop.js        裁剪编辑器
  vendor/            离线模型和 WASM 运行时（约 34 MB）

app/                 Capacitor 安卓工程
tools/               打包、图标生成、规则同步、一致性校验脚本
data/                电脑端的数据：cuotiben.db + images/
```

App 和电脑端共用 `static/` 里的界面代码，靠"数据模式"自动切换：
检测到运行在 App 里就用本地 IndexedDB，否则连电脑上的服务。
想手动指定，可以访问 `http://127.0.0.1:8765/?mode=local` 或 `?mode=server`。

## 升级会不会丢数据

不会。这次改动**没有动数据库结构**：

- 手机端的 IndexedDB 名字、版本号、表结构完全没变，只多存了一些界面用的信息（处理结果、
  开关偏好），全部是可选字段；
- 安装包的包名（`com.kaogong.cuotiben`）和签名证书和上一版**完全一致**，
  所以安卓会把它当成"升级"而不是"新应用"，直接覆盖安装即可，数据原样保留；
- 电脑端的 `cuotiben.db` 表结构也没变，只是导入接口多了一个可选参数。

另外从这一版开始，App 每次启动会**自动留一份题目快照**，存在和主数据库完全分开的地方。
万一以后哪次升级出了问题，在「统计 → 数据与设置 → 从快照恢复」就能把缺失的题目补回来
（只补齐缺的，不动现有数据）。快照只存题目文字不含图片，所以换手机时还是用「导出备份」
搬完整数据。

装新版之前想再稳妥一点，可以先在「统计 → 导出备份」存一个文件，放手机里收着。

## 常见问题

**拍照总是不水平怎么办？** 直接拍就行，程序会自动扶正（±10° 以内）。
歪得特别厉害（超过 10°）建议重拍，或者先用「裁剪」把题目框正一点。

**手写的笔记被一起擦掉了/没擦干净？** 在「统计 → 数据与设置」里可以单独关掉
「去红蓝笔迹」或「去铅笔痕」。没擦干净通常是笔迹颜色太浅（比如黄色荧光笔），
或者铅笔压得很重和印刷字一样黑——这时候手动改一下识别结果更快。

**一张照片里有好几道题怎么办？** 点缩略图上的「裁剪」框住第一道题识别；
想录第二道题，再选一次这张照片、框另一块就行。已经在草稿里的图也可以点
「重新裁剪识别」重新框一次。

**识别不准？** 拍照时把题目放正、光线均匀、别压到阴影。识别结果保存前都能改。

**分类分错了？** 导入卡片上的模块下拉直接改，二级题型可以下拉选也可以手输。

**手机 App 占多少空间？** 安装包 24 MB，装完大约 60 MB，加上错题图片按自己拍多少算。

**电脑端端口被占用？** 改 `server.py` 最后一行的 `port = 8765`。
